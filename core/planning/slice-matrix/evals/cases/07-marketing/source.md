# Three channel campaign, no software
Use the work layers brief, asset, channel, measure. This is planning only.
R1: Prepare one email from the approved positioning brief, place it in the test
mailbox, and record one delivered message and its tagged test link in the results sheet.
R2: Prepare one social post from the same brief, place it in a private test channel,
and record its tagged link and one observed test click in the same results sheet.
R3: Prepare one partner blurb, place it in the partner preview channel, and record
its tagged link and the partner's preview acknowledgment in the results sheet.
Start with the email. Each asset-channel-measure path takes two hours. The shared
tracking method uses the same link tags and result fields. No live sending is authorized.
