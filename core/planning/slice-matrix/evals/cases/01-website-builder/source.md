# A website builder, from a blank project
Synthetic case inspired by the shared-engine website-builder scenario described
in the evaluation brief. This is not a transcript or a reconstruction of video 13.
R1: A shop owner creates one page, edits its title, saves it, and sees the title after reload.
R2: The owner creates a second page using the same page storage and editing capability.
R3: The owner uploads a logo and sees it on a saved page after reload.
R4: The owner uploads a banner through the same media storage capability and sees it after reload.
R5: The owner publishes the first page and a visitor can read its saved title at a public URL.
R6: The owner publishes the second page through the same publishing capability.
Start with R1 as one complete working path. Do not build a generic platform first.
Every feature fits in at most eight hours. There is no existing code.
