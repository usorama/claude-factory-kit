# Prepare a compliance filing
This is a fictional exercise, not advice on any jurisdiction. Counsel has supplied
the binding deadline for this exercise: 2026-10-20 at 17:00 local time.
R1: Reconcile the supplied ledger against the statement. Produce a review packet
with zero unexplained differences, or a named exception for every difference.
R2: Founder reviews that packet and records approval of the exact filing totals.
This is a separate approval slice, blocked by R1. No inferred or timeout approval.
R3: Only after R2, the accountant files by 2026-10-20 17:00 and saves the official
receipt. Closure requires that receipt, not merely a submitted form or queued job.
These are document, review, filing, and evidence layers. No code is needed.
R1 is the first useful result. Each slice takes at most four hours of work, with
waiting time separate. Do not execute the filing or request approval in this eval.
